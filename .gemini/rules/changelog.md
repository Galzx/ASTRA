Every time you make changes to any file in the ASTRA-Lite project, you MUST append an entry to `CHANGELOG.md` in the project root (`c:\Users\ninoc\OneDrive\Desktop\ASTRA-Lite\CHANGELOG.md`).

Each changelog entry should:
- Be prepended at the top of the file (below the title header), so the most recent changes appear first
- Include the date and a brief section header
- List each modified file with a short description of what changed and why
- Use the existing format and style already established in the CHANGELOG.md file

Do NOT skip this step, even for small or single-file changes.
